# Java 25 — la librería compila para Java 25 LTS

**Fecha:** 2026-11-01

## Qué se implementó

- `pom.xml`: `java.version` y `sonar.java.source` pasan de 17 a 25.
- CI (`ci.yml`) y JitPack (`jitpack.yml`) construyen con JDK 25.
- README, `CLAUDE.md` y `CONTRIBUTING.md`: requisito Java 25.
- `docs/bitacora/` creado con su plantilla.

## Decisiones

- Se sube después de que todos los consumidores pasaran a Java 25: un jar con bytecode 25 no carga en un JDK menor.
- Se publica como versión menor (1.5.0): los únicos consumidores ya están en Java 25.
